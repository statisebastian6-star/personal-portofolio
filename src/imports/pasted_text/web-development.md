Section 1: Interactive Features – HugPups Section intro paragraph: HugPups is an 8-page therapy dog visitation website built in plain HTML, CSS and JavaScript with no frameworks. I deliberately wrote the code with inline comments throughout so the codebase doubles as a learning reference. Below are the main interactive features I built into the site. Display as a 2x2 grid of cards. Each card has a heading, an image placeholder for a screenshot, an image placeholder for a code snippet, and a short description. Card 1 — Star Rating Picker An interactive 5-star rating component on the reviews form. When a user clicks or hovers a star, all stars up to that position fill in. The selected rating is submitted alongside the written review. Built using JavaScript event listeners and CSS class-toggling. Card 2 — Dynamic Review Injection When a user submits a review, it appears on the page immediately without a refresh. The form data is read, wrapped in a styled element, and inserted into the reviews container using JavaScript's createElement and appendChild methods. Card 3 — Form Validation Client-side validation on every form across the site. Required fields are checked and email addresses are validated against a standard pattern. If validation fails, an inline error message appears next to the field. Built using JavaScript event listeners and regex pattern matching. Card 4 — FAQ Accordion An expandable / collapsible FAQ system. Clicking a question toggles its answer open or closed, with only one answer open at a time. Built using JavaScript class-toggling and smooth CSS height transitions. Section 2: Interactive Features – Rust Toolkit Section intro paragraph: The Rust Toolkit is a multi-page interactive encyclopedia for the survival game Rust. From a web development perspective it features a searchable items database, a recursive crafting tree, a raid cost calculator, and tab-based navigation. I designed the structure and used AI assistance for parts of the JavaScript implementation, treating AI as a development tool similar to Stack Overflow or documentation. Display as a 3-column row of cards. Each card has a heading, image placeholder for screenshot, image placeholder for code snippet, and short description. Card 5 — Search and Filter Real-time search and filtering on the items database. Typing in the search box filters items by name as the user types. Two filter button rows — one for category (Weapon, Armor, Tool, Resource etc.) and one for rarity — combine with the search text to narrow results. Card 6 — Recursive Crafting Tree Selecting an item from a dropdown displays its full ingredient breakdown, with sub-ingredients expanding all the way down to raw materials. The total resource cost is calculated and displayed at the top. Built using a recursive function that walks each ingredient's own recipe. Card 7 — Tabbed Navigation A consistent top navigation bar across every page of the toolkit, with the active page highlighted in the orange accent colour. Built using shared HTML/CSS components and a small piece of JavaScript that adds an active class to the current page's link.
